# Portfolio Website

A simple, clean portfolio website built with HTML, CSS, and JavaScript.

## Getting Started

1. Open `index.html` in your web browser
2. Customize the content in `index.html` with your information
3. Modify colors and styles in `style.css` as needed

## Structure

- `index.html` - Main HTML structure
- `style.css` - Styling and layout
- `script.js` - Smooth scrolling navigation

## Customization

Edit the following in `index.html`:
- Replace "Your Name" with your actual name
- Update the About section with your bio
- Add your projects to the Projects section
- Update contact information

## Deployment

You can deploy this website to:
- GitHub Pages
- Netlify
- Vercel
- Any static hosting service
